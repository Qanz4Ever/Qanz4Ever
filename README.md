  - [Pterodactyl-Security](https://github.com/Qanz4Ever/Pterodactyl-Security) — Infrastructure defense and anti-tamper access protection.
- ⚡ **Core Strengths**: C# / .NET 8, Node.js, Python, Bash automation, RESTful architectures, Linux administration, and perceptual media processing.
- 💬 **Ask me about**: Desktop development, systems automation, media algorithms, server administration, and full-stack web applications.
